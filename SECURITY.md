# Reporting a WerkZ security issue

Please report suspected vulnerabilities privately through the repository's GitHub private vulnerability reporting feature when available, or through the published WerkZ contact channel with the subject **SECURITY**. Do not put an unpatched exploit or customer data in a public issue.

Include the affected product/version, steps to reproduce, expected impact and a safe contact address. We will acknowledge, assess affected versions and coordinate remediation and disclosure. This document does not promise a fixed response time or claim certification.

For product support and end-of-support state, use version-specific release metadata. CRA or other statutory reporting applicability is assessed for the affected product and incident, not assumed for every report.

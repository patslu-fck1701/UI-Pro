# Testing model

The DeutschZ Testzentrale remains structurally unchanged for now. Precise test possibilities are expanded event by event before any deeper evidence-model migration.

General WerkZ evidence principle: a confirmation applies to the concretely defined claim, observed scope, relevant development state, dependencies and test conditions. A narrow confirmation must not be generalized into whole-system confirmation.

Historical valid evidence remains historical evidence when later integrations create a new state; integration/regression evidence is tracked separately.

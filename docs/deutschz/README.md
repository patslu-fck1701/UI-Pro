## Wichtige Trennung

Die technische Major-Event-Rotation und die persönliche Hauptstory sind zwei verschiedene Systeme.

Technische Rotation bleibt vorerst:
`KOTH → CourierZ → RAVEN → AIConvoyZ`

Persönliche Hauptstory:
`KotHZ → AIConvoyZ → ToxicZ → ATM RaidZ (optional) → PropertyZ → CourierZ → RAVEN → BattlegroundZ → Operation DeutschZ`

King of the Hill, CourierZ und RAVEN bleiben funktional vorerst unverändert. Ihre bestehende Eventlogik wird nur mit Story-Bedeutung verknüpft. Operation EclipseZ ist verworfen und kein aktueller Story-/Implementierungszweig.

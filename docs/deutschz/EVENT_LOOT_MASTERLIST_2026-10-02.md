## Rules
- In the authoritative DeutschZ configuration, `nominal=0` means EVENT/SPECIAL-only loot: no regular map/CE spawn. Event assignment still depends on role, rarity and balance.
- Evaluate CE spawn, rarity, event usage and weapon/equipment role together.
- KOTH is the current balance reference.
- Event crates mix SPECIAL/EVENT + HYBRID/HIGH EVENT + appropriate MAP/CE filler.
- Never invent TTC/FOG/NBC classnames.

## SPECIAL / EVENT
TTC_Beowulf; TTC_GEVAR43 family; TTC_TAVOR; TTC_TAVOR_DMR; nominal-0 ModDMR 5.56/7.62 families; TTC_AKMod / TTC_AKModPK families. Anzio20mm is an extremely rare SPECIAL/ENDGAME exception.

## HYBRID / HIGH EVENT
TTC_AWM; TTC_HK417; TTC_M24_NEW_Black; TTC_M110_Black; TTC_SCARHBlack; selected M24/R700/M14/M1A/M4DMR and high-grade assault variants.

## MAP / CE filler
Frequent military rifles, SMGs, pistols and hunting/historical weapons can support event crates or AI loadouts, but should not normally be the sole high-end jackpot.

## FOG
Use role-appropriate helmets, NVG, tactical clothing, backpacks, headsets and plate carriers. KOTH-backed examples include FOG_Helmet_Airframe_OD, FOG_ANVIS9, FOG_AEM01_Jacket_Black, FOG_Bag_ArcteryxLEAF_Black and FOG_AMP_Headset_Black. Prefer serious military colourways for RAVEN; do not treat every nominal-0 FOG item as event gear.

## RAVEN
RECON: TTC_TAVOR_DMR, TTC_GEVAR43, TTC_AWM, TTC_M110_Black, TTC_M24_NEW_Black, TTC_M4DMRDesert/OD/SNOW, ModDMR family + compatible equipment.

ASSAULT: TTC_Beowulf, TTC_TAVOR, TTC_HK417, TTC_SCARHBlack, TTC_SCARLBlack, TTC_HK416Black, TTC_MK18_Black, TTC_MCX_300blk, AKMod/AKModPK + compatible FOG.

NBC/SURVIVAL: ABC/NBC set, filters, medical and survival value; no guaranteed endgame primary. Normal TTC sidearm/secondary candidates include TTC_Glock17, TTC_P320, TTC_M9_Custom, TTC_UZI, TTC_MP7A1, TTC_MP5SD, TTC_PP91.
